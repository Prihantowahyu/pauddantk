# Folder APK Android (TWA)

Folder ini digunakan untuk menyimpan berkas installer Android:
- **`harsha-edu.apk`**: Berkas APK siap pasang untuk HP/Tablet Android.

## Cara Menaruh APK:
1. Setelah membuat APK (melalui **PWABuilder** atau **Bubblewrap**), beri nama file menjadi `harsha-edu.apk`.
2. Simpan di folder ini: `apk/harsha-edu.apk`.
3. Lakukan `git add apk/harsha-edu.apk` dan `git push` ke GitHub.
4. Tombol **"🤖 Unduh APK"** pada aplikasi web akan langsung mengunduh file ini secara otomatis.
